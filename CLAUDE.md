# PLANN

## Frontend Engineering Standards

- Use modern-web-guidance before implementing
  or modifying frontend UI, CSS, or client-side JS.
- Follow browser compatibility and Baseline guidance.
- Maintain compatibility with React 19 and Capacitor 7.
- Test responsive layouts on mobile and desktop.
- Preserve existing API contracts and application behavior.
- Never introduce new dependencies when native
  browser APIs provide a suitable solution.
- Do not replace working components merely to
  adopt newer web standards.
- Prefer progressive enhancement and lightweight fallbacks.
